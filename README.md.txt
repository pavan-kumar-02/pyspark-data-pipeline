# PySpark Sales Data Pipeline

## Overview
This project demonstrates a scalable ETL pipeline using PySpark for processing sales data.

## Tech Stack
- PySpark
- Python
- CSV Data Source

## Features
- Data ingestion from CSV
- Data cleaning and transformation
- Aggregations (category-wise sales)
- Filtering high-value transactions
- Output storage

## How to Run
1. Install PySpark
2. Run:
   python scripts/sales_pipeline.py

## Key Concepts Used
- DataFrames
- Transformations
- Actions
- Aggregations
- Distributed processing
